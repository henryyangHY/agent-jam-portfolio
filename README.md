# Agent Jam: Build Your Portfolio

In the next 30 minutes you will turn Jordan Lee's sample page into your own personal website, without writing any code yourself. You describe what you want. Claude does the work.

**What is in this folder**

| File | What it is |
|---|---|
| `index.html` | Your website's content. Double-click it to open it in your browser. |
| `style.css` | Your website's look: colors, fonts, spacing. |
| `about-me.md` | A short form about you. Claude uses it to fill in your website. |
| `CLAUDE.md` | Instructions Claude reads every time you start a session in this folder. |

---

## Step 1. Get the project onto your laptop (7 min)

1. Open the **Claude** app and go to the **Code** tab
2. Start a new **local** session and choose your **Documents** folder
3. Copy this into the chat and press Enter:

```
Help me copy this project to my device, then open index.html in my browser: https://github.com/henryyangHY/agent-jam-portfolio
```

4. You should see a sample page for "Jordan Lee". That is your starting point.
5. Start a **new** local session, and this time choose the new **agent-jam-portfolio** folder. From now on, work in this session.

> When Claude asks for permission to run something or edit a file, read what it says, then click **Allow**.

## Step 2. Make it yours (7 min)

1. Open `about-me.md` and fill it in. Short answers are fine.
   (Or skip it and paste your resume or LinkedIn "About" section into the chat.)
2. Send this:

```
Read about-me.md and replace Jordan Lee's information on my website with mine. Keep the current layout. If I left something blank, remove that part.
```

## Step 3. Pick a style (7 min)

1. Send this:

```
Create 3 very different visual styles for my website as separate pages I can compare: option-1, option-2 and option-3. For example: clean and minimal, bold and colorful, dark and modern. Keep my content the same. Open all three in my browser.
```

2. Pick your favorite, then send this (change the number):

```
I like option 2. Make my real website (index.html and style.css) look exactly like option 2, then delete all the option-1, option-2 and option-3 files.
```

## Step 4 (optional). Put it online with GitHub Pages

Right now your website only lives on your laptop. This step gives it a public link you can share with anyone.

> Your website will be public. Only publish what you are happy for anyone to see.

```
Publish my website on GitHub Pages with my own GitHub account. Create a new public repository called my-portfolio and upload only the files the website needs: index.html, style.css and the fonts folder. Then turn on GitHub Pages. I'm new to GitHub, so if I need to sign in or click something in the browser, tell me exactly what to do, one step at a time. When it's live, give me the link.
```

- The link will look like `https://your-username.github.io/my-portfolio/`.
- The first time, it can take 1 to 2 minutes before the link works. If you see "404", wait a moment and refresh.
- Not finished by the end of the workshop? No problem. Send the same prompt tonight.
