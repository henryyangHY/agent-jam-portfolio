# Agent Jam: Build Your Portfolio

In the next 30 minutes you will turn this plain page into your own personal website, without writing any code yourself. You describe what you want. Claude does the work.

**What is in this folder**

| File | What it is |
|---|---|
| `index.html` | Your website. Double-click it to open it in your browser. |
| `about-me.md` | A short form about you. Claude uses it to fill in your website. |
| `CLAUDE.md` | Instructions Claude reads every time you start a session in this folder. |

---

## Step 1. Get the project onto your laptop (8 min)

1. Open the **Claude** app and go to the **Code** tab
2. Start a new **local** session and choose your **Documents** folder
3. Copy this into the chat and press Enter:

```
Clone https://github.com/henryyangHY/agent-jam-portfolio into this folder, then open index.html in my browser.
```

4. You should see a plain page for "Jordan Lee". That is your starting point.
5. Start a **new** local session, and this time choose the new **agent-jam-portfolio** folder. From now on, work in this session.

> When Claude asks for permission to run something or edit a file, read what it says, then click **Allow**.

## Step 2. Make it yours (7 min)

1. Open `about-me.md` and fill it in. Short answers are fine.
   (Or skip it and paste your resume or LinkedIn "About" section into the chat.)
2. Send this:

```
Read about-me.md and replace Jordan Lee's information on my website with mine. Keep the current layout.
```

## Step 3. Pick a style (8 min)

1. Send this:

```
Create 3 very different visual styles for my website as separate files: option-1.html, option-2.html, option-3.html. For example: clean and minimal, bold and colorful, dark and modern. Keep my content the same. Open all three in my browser so I can compare.
```

2. Pick your favorite, then send this (change the number):

```
I like option 2. Apply that style to index.html, then delete the three option files.
```

## Step 4. Add a feature (7 min)

```
Add an FAQ section to my website, with an "FAQ" link in the top menu that scrolls to it. Write 4 questions people might ask me, based on my information. Each answer should open and close when I click the question.
```

```
Add a subtle animation so each section fades in as I scroll down.
```
